# Xeno 3.0 - Super Advanced AI Agent System

The world's most powerful autonomous AI agent with god-tier capabilities.

## 🚀 Features

- **Neural Orchestrator v3**: Multi-label intent classification, priority queues, resource allocation
- **HyperAgent Controller**: 5 agent types, 100+ concurrent execution
- **Omni-Memory System**: 9-tier memory with knowledge graph and collective memory
- **Infinite Tool Ecosystem**: 100+ native tools + MCP servers + plugin marketplace
- **Multimodal Perception**: Vision, Audio, Text, Haptic controls
- **Self-Improvement**: Code rewriting, skill creation, architecture evolution
- **God-Tier UI**: Next.js 14 + Electron 28 with real-time dashboard, voice interface

## 🚀 Quick Start

### Prerequisites
- Python 3.11+
- Node.js 20+
- uv package manager
- pnpm

### Backend Setup

```bash
cd backend
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
python -m core.main
```

### Frontend Setup

```bash
cd frontend
pnpm install
pnpm dev
```

### Desktop App

```bash
cd frontend
pnpm electron:dev
```
